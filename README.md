# LoRa_finalproject

GitHub repo for final Data Wrangling Project

## N2O emissions from a gas flux chamber in a corn field

**Summary**

This repository includes codes to analyse the emision of greehouse gasses through the area obtained from Gas Chromatography readings.

The overall objective is to calculate the flux (mg N m⁻² h⁻¹) of N2O emissions, and plot in in a line graph across 5 days.

The data set includes information of three chemical treatments in two field conditions. The field conditions along with their chemical treatments are included in a separate data frame.

**Dependencies**

ggplot
